# Брэйни — анимации

Из утверждённых кадров `Pro_Insult_App/Брэйни/brain_*_png_1080.zip` и `Брэйни/эмоции ожидания/` (1080×1080, 30 кадров/с, прозрачный фон):
общая рамка по всем кадрам всех 8 анимаций (149, 140)–(939, 1021), уменьшено до 260×290, каждый второй кадр (15 кадров/с),
анимированный WebP с прозрачностью (качество 78). `idle.png` — первый кадр, спокойная поза.

| Файл | Эмоция | Длина |
|---|---|---|
| happy.webp | счастье | 4,5 с |
| sad.webp | грусть | 5 с |
| angry.webp | злость | 4,5 с |
| talk.webp | разговор | 5 с |
| tired.webp | переминается с ноги на ногу (раз в 3 мин, если не занят) | 7 с |
| fall-asleep.webp | засыпает, играет один раз (5,5 мин без действий) | 3 с |
| sleep.webp | спит, по кругу | 6 с |
| wake-up.webp | просыпается, играет один раз | 2 с |

Все ролики начинаются и кончаются в одной спокойной позе — их можно переключать без скачка.

Сон стыкуется кадр в кадр: спокойная поза → fall-asleep → sleep → wake-up → спокойная поза.
